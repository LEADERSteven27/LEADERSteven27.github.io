# 个人资料

## Day 1 光通信基础与色散补偿

### 光通信系统指标

- 误码率（BER）：
    - 定义：单位时间内错误比特数占总比特数的比例。
    - 常见要求：$10^{-9} \sim 10^{-12}$。
    - 测试仪器：BERT。
### Q 值

- 用途：低 BER 直接仿真耗时很长，常用 Q 值作为替代指标。
- BER 与 Q 值关系：

$$
BER = \frac{1}{2} \operatorname{erfc}\left(\frac{Q}{\sqrt{2}}\right)
$$

- 定义：

$$
Q = \frac{I_1 - I_0}{\sigma_1 + \sigma_0}
$$

- 常见要求：$Q > 6$，对应 $BER < 10^{-9}$。

### 眼图与功率代价

- 眼图：
    - 将接收端信号在一个比特周期内叠加形成。
    - 眼图越张开，信号质量越好。
- Power penalty：
    - 额外器件带来的功率代价。
    - 含义：为了达到相同 BER，接收端所需增加的光功率。

### 调制方式

- 直接调制：
    - 用电流直接调制发光器件。
    - 优点是简单、低成本，适合低速场景。
- 外调制：
    - 激光器加外调制器。
    - 器件更多，但适合高速传输。
- 常见码型：
    - RZ：归零码。
    - NRZ：非归零码。

### 色散与补偿

- 色散来源：
    - 激光器存在带宽，不同波长在光纤中传播速度不同，导致脉冲展宽。
    - 总色散 = 材料色散 + 波导色散。
- 展宽量：

$$
\Delta T = D(\lambda) \cdot \Delta \lambda \cdot L
$$

- 光纤类型：
    - 普通单模光纤：1310 nm 附近总色散接近 0。
    - Dispersion-shifted fiber：1550 nm 附近总色散接近 0。
    - Dispersion-flattened fiber：用于平滑色散曲线。
- 色散补偿管理：
    - 后补偿。
    - 前补偿。
    - 前后补偿。
    - 色散补偿光纤（DCF）的色散为负。

### OptiSystem 操作要点

- 全局设置：
    - 比特率 5 Gbps。
    - Sequence length：128。
    - Samples per bit：64。
    - 去掉 noise 勾选。
- 常见链路：
    - EML -> SMF1 -> OA1 -> SMF2 -> OA2 -> PD -> OSA。
    - DCF 可放在 SMF 前后形成前补偿、后补偿或前后补偿。
- CW laser 扫描：
    - Power mode 改为 sweep。
    - 设置 13 个点，-6 到 30 dBm 线性扫描。
- 软件细节：
    - 高 DPI 兼容性：属性 -> 兼容性 -> 更改高 DPI 设置 -> 替代高 DPI 缩放行为，选择“系统”。
    - Component library 右键可以 find component。
    - PIN PD 改频率前先改模式为 normal，再把单位从 Hz 改为 THz。
    - 增加传输距离时可考虑 loop。

## Day 2 DWDM 与 FWM

### DWDM

- 定义：
    - 在同一根光纤中使用多个不同波长承载独立数据流，提高传输容量。
- 优点：
    - 不需要光-电-光转换。
    - 支持不同通信协议、比特率和数据格式。
    - 只增加波长即可扩容，扩展性较好。
- 系统链路：
    - 多个传输源 -> DWDM 复用器 -> 光纤与放大器 -> DWDM 解复用器 -> 多个接收端。
- WDM 类型：
    - CWDM：波长间隔较大，适合中短距离，成本较低。
    - WDM：常见 1310 nm 和 1550 nm 波段。
    - DWDM：波长间隔较小，适合长距离和大容量。
- 标准与波段：
    - G.692。
    - C-Band：1530.3 nm - 1567.1 nm，可划分约 81 个 50 GHz 间隔通道。
    - L-Band：1570 nm - 1620 nm。
- 主要问题：
    - 损耗。
    - 串扰。
    - 设备复杂度和成本。
    - 通道间隔与串扰之间的权衡。

### DWDM 仿真实验

- 基本要求：
    - 40 Gbps。
    - 16 通道。
    - Q > 6。
- 全局变量：
    - Bit rate：40 Gbps。
    - Sequence length：1024。
    - Samples per bit：64。
    - 去掉 noise 勾选。
- 设计路径：
    - 先做 300 km 单通道优化。
    - 再扩展到多通道设计。
    - 分析通道数、波长间隔、传输距离对 Q 值的影响。

### FWM

- 定义：
    - 四波混频是三阶非线性效应。
    - 两个或多个频率分量在非线性介质中相互作用，产生新的频率成分。
- 来源：
    - 三阶非线性。
    - 能量守恒。
    - 动量守恒 / 相位匹配条件。
- 闲频光数量：

$$
2C(N,2)+3C(N,3)
$$

- 影响因素：
    - 相位匹配越好，FWM 越强。
    - 通道间隔越小，FWM 越强。
    - 色散越小，FWM 越强。
- 抑制方式：
    - 增大光纤有效面积。
    - 适当保留色散，避免完全补偿。
    - 非均匀波长间隔。
    - 偏振分配。

## Day 3 EDFA

- 光放大器类型：
    - 半导体光放大器。
    - 光纤型放大器，例如 EDFA。
    - 分布式光纤放大器，例如 Raman 放大器。
- 应用位置：
    - In-line amplifier。
    - Power amplifier。
    - Pre-amplifier。
- EDFA 参数：
    - 工作波段：C 波段（1530-1565 nm）。
    - 最大增益：约 30 dB。
    - 典型长度：约 10 m。
    - 泵浦波长：980 nm 或 1480 nm。
    - 噪声来源：自发辐射；理论噪声系数约 3 dB，实际约 6-8 dB。
- 设计关注：
    - 增益饱和。
    - ASE 噪声。
    - 增益平坦化，可加入 Gain Flattening Filter。

## Day 4 Raman 与 Hybrid 放大器

### Raman 放大器

- 拉曼效应：
    - 光子与介质分子相互作用后频率发生变化，形成拉曼散射。
- 散射类型：
    - 瑞利散射：弹性散射，频率不变。
    - 斯托克斯散射：频率降低，波长变长。
    - 反斯托克斯散射：频率升高，波长变短。
- 特点：
    - 斯托克斯散射通常强于反斯托克斯散射。
    - 高泵浦功率下，Raman 放大器可能优于 EDFA。
- 相关放大器：
    - FRA。
    - TDFA。
    - PDFA。

### Hybrid 放大器

- 定义：
    - 将 Raman 放大器和 EDFA 组合，扩展增益带宽。
- 设计目标：
    - 增益优化。
    - 增益平衡。
    - 控制噪声系数。
- 典型大作业：
    - 超宽带、平坦化光放大器的优化设计。

## Day 5 PON 与 Metro

### PON

- 定义：
    - 光纤分配网络是一种点到多点的光纤通信技术。
    - 通过光分束器将中心局信号传输到多个用户端。
- 接入网络类型：
    - Point-to-point。
    - AON。
    - TDM-PON，例如 BPON、EPON、GPON。
    - WDM-PON。
- 核心器件：
    - 光分束器。

### Metro

- 定义：
    - 城域网是城市范围内的光纤通信网络，用于连接局域网和广域网。
- 架构：
    - Ring。
    - Mesh。
