## 光通信简介

- 误码率（BER）、Q 值和眼图是常见系统质量指标。
- 产生 01 信号：
  - 直接调制：电流调制发光二极管，简单、低速、低成本。
  - 外调制：激光器 + 调制器，需要额外器件，适合高速场景。
- BER：
  - 定义：一秒内传输的比特数中，错误比特数占总比特数的比例。
  - 范围要求：$10^{-9} \sim 10^{-12}$。
  - 测试仪器：BERT。
- Q 值：
  - 仿真 BER 有困难：要得到很低 BER 的结果需要长时间仿真，例如 $10^{-12}$ 量级可能需要极长时间，因此常用 Q 值作为替代指标。
  - BER 与 Q 值关系：

$$
BER = \frac{1}{2} \operatorname{erfc}\left(\frac{Q}{\sqrt{2}}\right)
$$

  - Q 值定义：

$$
Q = \frac{I_1 - I_0}{\sigma_1 + \sigma_0}
$$

  - 范围要求：$Q \gt 6$，对应 BER 为 $\lt 10^{-9}$。
- 眼图：
  - 定义：将接收端信号在一个比特周期内叠加形成的图形。
  - 作用：直观观察信号质量，眼图越“张开”，信号质量越好。
- Power penalty：
  - 额外器件的“功率代价”。
  - 定义：在接收端，为达到相同 BER，所需增加的光功率。

## 色散与补偿

- 色散：激光器有带宽，不同波长的光在光纤中传播速度不同，导致脉冲展宽。
- 展宽量：

$$
\Delta T = D(\lambda) \cdot \Delta \lambda \cdot L
$$

- 总色散 = 材料色散 + 波导色散。对单模光纤，1310 nm 附近总色散为 0。
- Dispersion-shifted fiber：在 1550 nm 附近总色散为 0。
- Dispersion-flattened fiber：用于平滑色散曲线。
- 补偿方式：
  - 后补偿。
  - 前补偿。
  - 前后补偿。

## 光通信网络分类

- Channel spacing：WWDM / CWDM / NWDM / DWDM。
- Interfaces：open / half-open / integrated。
- 损耗：吸收、散射。
- 色散：模式、波导、材料。
- 信噪比：EDFA 中的 ASE、accumulated noise。
- 非线性效应：自相位调制（SPM）、交叉相位调制（XPM）、四波混频（FWM）、受激布里渊散射（SBS）。

## 光纤传输理论关键词

- 光在光纤中的波动方程。
- 薛定谔方程。
- 正常/反常色散。
- 啁啾。
- 线性传播：傅里叶变换。
- 零色散：只改变相位。
- 色散 + 非线性：分成两段光纤分别考虑色散/非线性。
- 孤子。

## 色散补偿仿真

### 基本应用

- 随机码与伪随机码。
- 归零码（RZ）与非归零码（NRZ）。
- 直接调制激光（DML）。
- 外调制激光（EML）。
- 普通单模光纤传输模型：EML -> SMF1(80 km, -0.2 dB/km) -> OA1(16 dB) -> SMF2 -> OA2 -> PD -> OSA。

### 色散补偿管理（DCM）

- 色散补偿光纤（DCF）：色散为负。
- 前补偿：EML -> DCF1 -> SMF1 -> OA1 -> DCF2 -> SMF2 -> OA2 -> PD -> OSA。
- 后补偿：EML -> SMF1 -> DCF1 -> OA1 -> SMF2 -> DCF2 -> OA2 -> PD -> OSA。
- 前后补偿：对第一段后（前）补偿，对第二段前（后）补偿。
- 全局设置：比特率 5 G，sequence length 128，samples per bit 64，noise 去掉勾选。
- CW laser 扫描：power mode 改为 sweep，设置 13 个点，-6 到 30 dBm 线性扫描。

### 软件操作

- 兼容性修改：右键软件快捷方式进入“属性” -> “兼容性” -> “更改高 DPI 设置” -> 勾选“替代高 DPI 缩放行为”，选择“系统”。
- 及时保存。
- Component library：右键可以直接 find component。
- PIN PD：改频率前先把模式改为 normal，再把单位从 Hz 改为 THz。
- 制表与绘图。
- 拓展：增加传输距离时可采用 loop。

## DWDM（密集波分复用）

### 定义

DWDM 是一种光纤通信技术，通过在同一根光纤上使用多个不同波长的光信号传输数据，从而提高光纤传输容量。每个波长可以携带独立数据流，因此同一条光纤可以同时传输大量数据。

### 优点

- 不需要光-电-光转换，减少信号损耗和延迟。
- 支持不同通信协议和比特率。
- 低成本增加传输容量：只需要增加波长。
- 支持不同数据格式。
- 扩展性好。

### 概览

- 链路：A/B/C（三个传输源，使用三种不同波长） -> DWDM 复用器 -> 光纤（+ 放大器） -> DWDM 解复用器 -> X/Y/Z（接收端）。
- 潜在问题：损耗、串扰。

### WDM 类型

- CWDM（粗波分复用）：波长间隔较大，适用于中短距离传输，成本较低。
- WDM：1310 nm 和 1550 nm 波段，适用于中长距离传输，成本适中。
- DWDM（密集波分复用）：波长间隔较小，适用于长距离传输，成本较高，但传输容量大。

### 缺点

- 对于低通道数并不划算，因为 DWDM 设备成本较高。
- 引入复杂光学器件和管理系统，增加系统复杂性。
- 同步网络并不能很好地支持 DWDM。

### DWDM 标准

- G.692。
- C-Band：1530.3 nm - 1567.1 nm，可划分出 81 个通道（50 GHz 间隔）。
- L-Band：1570 nm - 1620 nm。
- 对应光纤低损耗窗口和高增益窗口，适合长距离传输。

### Multiplexer and Demultiplexer

- Demultiplexing：将同一根光纤上的不同波长信号利用干涉分离出来。
- Multiplexing：demultiplexing 的逆过程。

### 有效面积

- 光纤有效面积（Aeff）是指光纤中传输模式的有效横截面积，通常以平方微米（μm²）为单位。
- 有效面积越大，光纤非线性效应越小，适合高功率传输。
- LEAF（Large Effective Area Fiber）：大有效面积光纤，适用于高功率和长距离传输，可降低非线性效应、提高信号质量。

### 仿真实验

- 要求：
  - 40 Gbps，16 通道。
  - Q > 6。
- 全局变量：
  - 比特率 40 Gbps。
  - Sequence length：1024。
  - Samples per bit：64。
  - 去掉 noise 勾选。

1. 300 km 单通道优化设计：
   - 外调制 -> loop（含色散补偿、功率补偿） -> Bessel 滤波器。
   - RZ 和 NRZ 的选择。
2. 多通道设计：
   - 分析通道数、波长间隔、传输距离对 Q 值的影响。
   - 使用 transmitter-receiver。

## FWM（四波混频）

### 定义

- FWM 是非线性效应。
- 简并四波混频（DFWM）：两个不同频率的光波在非线性介质中相互作用，产生新的频率成分。
- 总闲频光个数为 $2C(N,2)+3C(N,3)$，正比于 $N^3$，其中 $N$ 为通道数。

### 来源

- 三阶非线性效应。
- 能量守恒。
- 动量守恒 / 相位匹配条件。

### 影响因素

- 相位匹配越好，FWM 越强。
- 通道间隔越小，FWM 越强。
- 色散越小，FWM 越强。

### 抑制方法

- 增大光纤有效面积。
- 色散管理：不能完全补偿色散，适当保留色散。
- 非均匀波长间隔：理论可行，但现实中通道有国际标准。
- 偏振分配：光纤中偏振态会变化，难以实现。

### 仿真实验

- 现象展示：
  - 基本通信线路。
  - DSF 和 SMF 中 FWM 现象对比。
- 四种抑制方法。

## 光放大器

### Optical Amplifier

- 半导体光放大器。
- 光纤型放大器（EDFA）。
- 分布式光纤放大器（Raman 放大器）。

### 应用

- In-line amplifier。
- Power amplifier：放在 laser 后，常见于空间光通信。
- Pre-amplifier：放在接收端前面。

### EDFA

- 工作波段：C 波段（1530-1565 nm）。
- 最大增益：30 dB。
- 长度：10 m。
- 泵浦波长：980 nm、1480 nm。
- 增益（Gain）= signal output / signal input，其中 signal output 指 output signal without ASE noise。
- 增益饱和。
- 噪声：来源于自发辐射，理论约 3 dB，实际约 6-8 dB。
- 增益平坦化：加入 Gain Flattening Filter。

### Raman Amplifier

- 拉曼效应：光穿过透明介质时，光子与介质分子相互作用，导致频率变化，产生拉曼散射。
- 现象：海水的颜色并非来自天空。
- 瑞利散射：弹性散射，散射光波长与入射光相同。
- 斯托克斯散射：光子频率降低，散射光波长变长。
- 反斯托克斯散射：光子频率升高，散射光波长变短。
- 斯托克斯散射通常强于反斯托克斯散射，因为常温下分子处于基态的概率较高。
- 问题：虚拟能级不存在，无法测量。
- FRA：拉曼放大器。
- TDFA / PDFA。
- 拉曼放大器优势：高泵浦功率下，拉曼放大器优于 EDFA。

### Hybrid Amplifier

Hybrid amplifier 组合了拉曼放大器和掺铒光纤放大器，拓展了放大器的增益带宽。

## PON

- 光纤分配网络（PON）是一种点到多点的光纤通信技术，广泛应用于宽带接入网络。
- PON 系统通过光分束器将光信号从中心局传输到多个用户端，实现高效数据传输和资源共享。
- 核心器件：光分束器。

## Metro（城域网）

- Metro 网络是指城市范围内的光纤通信网络，主要用于连接不同局域网和广域网。
- 架构：ring / mesh。
