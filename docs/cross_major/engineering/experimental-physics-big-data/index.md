# 实验物理的大数据方法

<p class="lead">从实验物理问题出发，学习可复现的数据处理、科学计算与分析工作流。</p>

## 课程概览

- 开课学校：清华大学（THU）
- 课程目标：建立科学、透明、可复现的数据分析习惯，并能针对任务选择合适的工具。
- 内容主线：Git 与 Python、科学计算与可视化、GNU 命令行与数据生产线、关系代数与回归分析。
- 学习方式：公开资料包含讲义、课件和历年录像；课程使用 GNU/Linux 或其他 POSIX 环境，并以 Python 为主要计算语言。
